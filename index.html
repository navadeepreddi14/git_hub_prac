Understand the Basics

Two essential tools every developer should know.

🛠️

What is Git?

Git is a Distributed Version Control System. It tracks changes in source code and helps developers manage different versions of their projects.

  • Tracks code changes
  • Saves project versions
  • Restores previous versions
  • Supports branching and merging
  • Works on your local computer
🐙

What is GitHub?

GitHub is an online platform that hosts Git repositories. It helps developers store, share and collaborate on projects.

  • Stores code online
  • Shares projects with developers
  • Supports team collaboration
  • Provides pull requests
  • Manages project repositories

Git vs GitHub

Understand the difference clearly.

🛠️ Git

Version Control System

Works locally on your computer.

Tracks changes in source code.

Manages commits and branches.

🐙 GitHub

Cloud-based Git hosting platform

Stores repositories online.

Helps developers share code.

Supports collaboration.

Important Git Commands

Learn the commands used in daily development. Click Copy to copy a command.

git init

Initialize a Git repository

git status

Check file status

git add .

Stage all changes

git commit -m "message"

Save a commit

git push

Upload commits to GitHub

git pull

Fetch and integrate remote changes

git clone URL

Copy a remote repository locally

git log --oneline

View commit history

git branch

List branches

git fetch

Download remote updates

git merge branch-name

Merge another branch

git revert COMMIT_ID

Reverse a previous commit
