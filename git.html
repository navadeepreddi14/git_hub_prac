Git & GitHub 🚀

A Simple Beginner's Guide

🛠️ What is Git?

Git is a Version Control System (VCS). It tracks changes in source code and helps developers manage different versions of their projects.

  • Tracks code changes
  • Saves project versions
  • Restores previous versions
  • Works locally on your computer

🐙 What is GitHub?

GitHub is an online platform used to host Git repositories. It helps developers store, share and collaborate on projects.

  • Stores code online
  • Shares projects
  • Supports teamwork
  • Helps developers collaborate

⚡ Git vs GitHub

Git: Tracks and manages code changes.

GitHub: Stores and shares Git projects online.

⌨️ Important Git Commands

git init - Initialize Git

git status - Check file status

git add . - Stage all changes

git commit -m "first commit" - Save changes

git push - Upload code to GitHub

git pull - Get latest code

git clone URL - Copy a repository

Remember This! 💡

Git = Version Control System
GitHub = Online Code Hosting Platform
